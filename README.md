## Repository Structure
- `configs/experiment_config.json` — all hyperparameters, seeds, and grids
- `src/` — dataset setup, model definitions, training/evaluation utilities
- `splits/` — saved stratified train/val split (`seed=26002`) and Q4 10k stratified subset
- `logs/` — JSON metrics and visual arrays produced by each question script
- `figures/` — publication plots generated by `make_figures.py`
- `report/` — CVPR two-column HTML/PDF report
